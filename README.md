# 🎵 ListenBrainz Royalty Calculator

A Python web application built using Streamlit that fetches user history from the open-source ListenBrainz API and calculates simulated artist streaming royalties.

## 🚀 How to Run Locally

If you already have the project set up on your machine, follow these steps to launch it:

1. Open your terminal and navigate to the project directory:
   ```bash
   cd ~/listen-royalty-calculator

2. Activate the Python virtual environment:
   ```bash
   source venv/bin/activate

3. Launch the Streamlit server:
   ```bash
   streamlit run app.py


🛠️ First-Time Setup (For other machines)
